Start here: the app, Chat and Work

Get the app

Get the official ChatGPT app and sign in with your .edu account

Install ChatGPT on your computer first. The desktop app has the full set of features. Skip search results and ads, which often point to look-alike apps, and type the address below into your browser.

  1. On your computer, type chatgpt.com/download into the browser address bar.
  2. Download and install the app for Mac or Windows. On Windows, the Microsoft Store listing must show OpenAI as the publisher.
  3. Open the app and choose Log in. Enter your full campus email address, the one ending in .edu.
  4. Finish your campus sign-in. Check that your school's workspace name shows in the profile menu.

Signed in with a personal email? Log out and sign in again with your .edu address so you get your campus plan and its data rules. Want it on your phone later? In the App Store or Google Play, install ChatGPT only when the publisher is OpenAI.

Choose a mode

Chat or Work? Pick the mode at the top of the screen

Chat

Talk it through

Questions, quick drafts and explanations. You stay in the conversation and steer each reply.

Work

Hand off a job

Multistep tasks that produce a finished file, such as a report or slide deck. ChatGPT plans, uses your tools and reports back.

Quick win: Connect an approved document service, find five recent documents and ask for a one-line summary of each.

02

Projects, models and scheduled tasks

Organize

Put each ongoing job in a Project

A Project is a folder for chats, files and instructions about one job. Every new chat in it starts with that context, so you stop re-explaining.

Stop repeating yourself

Write project instructions once, such as audience, tone and format. Every chat in the project follows them.

Keep files in reach

Upload the syllabus, policy or template once. ChatGPT draws on it in every project chat.

Keep work separate

Project-only memory keeps a project's chats apart from your other conversations. Shared projects always use it.

  1. Pick one recurring job, such as a course, committee or weekly report.
  2. Create a project and name it after that job.
  3. Add two or three reference files and a few lines of instructions.
  4. Move related chats into the project. They pick up its instructions and files.

Share a project with Edit or Chat access when a colleague needs the same context. Use approved, de-identified files and follow your student-data policy.

Pick a model and effort

Match the model to the work. Start at low effort.

Low

Narrow and repeated

Try GPT-6 Luna at Low for sorting, extraction or a task with a clear right answer.

Low or Medium

Judgment across sources

Use GPT-6.1 Sol at Low or Medium for reports, reconciling documents and multistep work. Use the lowest effort that passes your check.

Higher, plus review

Consequential decisions

Increase effort when needed and add human review. Keep scope explicit. Consult your campus policy and the current Model Value Map.

Raise effort only after a result fails your check. Higher effort takes more time and usage. Menu labels and models vary by account and campus settings.

03

Usage credits and scheduled work

Check your allowance

Work and Codex share usage. Check what is left.

In the desktop app, open your profile menu > Settings > Usage & billing. Check that you are in CES ChatGPT. The monthly credits, five-hour limit and weekly limit are separate controls; read each remaining amount and reset time.

This allowance covers ChatGPT Work and Codex on plans that share credits. Regular Chat has separate limits. Credits are billing units, not tokens or a fixed number of messages. If a limit is reached, follow the reset or request options shown in your account; campus settings determine access.

Scheduled tasks

Let ChatGPT show up on a schedule

Monday

Open items and deadlines.

Wednesday

Find stale documents in an approved shared folder.

Friday

Draft a weekly update for review.

  1. Open Scheduled when available, or describe the task and when it should run.
  2. Choose a one-time or recurring schedule. Supported connected apps may offer event triggers.
  3. Review the account, sources, instructions and permissions before relying on a run.
  4. Check results and paused tasks in Scheduled.

Computer-bound tasks need that device available. Cloud tasks have different requirements. If a task's model retires, update it before the next run.

04

Find and use CES plugins

Find plugins

Open Customize > Plugins

In the desktop app, select Customize in the left rail, then Plugins. Public shows the public directory. Personal shows plugins you created or received.

Your CES collection

Choose CES ChatGPT, then add a plugin

  1. Select CES ChatGPT. Open the plugin or use its + button, then choose Install plugin if prompted. Complete any required app connection.
  2. Start or open a chat in Work. Type @ and select the installed plugin, or use + > Plugins where shown. Then describe the task.
  3. For example, select AI Token Saver (ChatGPT Only) and ask: Help me choose a model and effort for this task. In a supported Codex task view, use Sources > Use plugins.

Install once, then select it in the chat where you need it. Availability and app permissions depend on your workspace.

Tools, skills and plugins

Find useful tools

Start with the work you already do

Google Drive, Gmail, Outlook

Documents and email

Find an approved document, summarize a thread or draft a reply.

Consensus, Quizlet

Research and study

Explore research or build practice flashcards, where available. Check sources and accuracy.

Canva

Design

Turn an outline into an event flyer, where available. Review the result before sharing.

Also check Calendar, SharePoint, Slack, Teams and Notion. Availability varies. Use approved campus services and de-identified examples; follow your student-data policy.

Make, build or borrow

Turn a task you repeat into a skill

Make a skill

You repeat a focused task, such as a weekly update or a document review.

Make a plugin

A workflow needs connected services or a bundle your team can reuse.

Install one

Search the Plugins directory before building a tool that already exists.

  1. Name one repeated task and its required result.
  2. Use Skill Creator where available. Describe the goal, steps and output format.
  3. Test with de-identified examples and refine the instructions.
  4. Share where your workspace permits. Name a maintainer and provide example prompts.

Good first skills: meeting notes to action items, policy-template checks or clearer help articles.

Habits from a working setup

Six habits that make AI more useful

  • Name the task, the tools and the result you want.
  • Ask ChatGPT to challenge your request if it is unclear.
  • Keep a short handoff in each project: done, next and open questions.
  • Verify facts and saves before you rely on them.
  • Search for an existing tool before you build one.
  • Add one new habit at a time.
Know the difference

A skill handles a task. A plugin bundles a workflow.

Custom GPTSkillPlugin
PurposeA separate chatbotReusable task instructionsSkills, files and connected capabilities
ToolsApps or custom actionsUses tools available to the taskMay include connected apps
SharingExisting GPT permissionsAccount and workspace controlsShare intentionally; apps authorize separately
06

Migrate GPTs and go further

If you built custom GPTs

Move your GPTs to plugins before they retire

Custom GPT retirement is scheduled for December 11, 2026.

What moves

Published GPT instructions become a skill. Reference files and supported connected apps can move with the plugin.

What needs attention

Custom actions and sharing settings need review or rebuilding. Existing conversations remain accessible.

Your move

When available, open My GPTs > Migrate to plugin. Test familiar requests in the same workspace before switching.

Follow your account or campus notice. For affected Enterprise workspaces, October 26 is the planned end of new GPT creation.

Advanced

Ready for more? Codex works with code

Codex is a third mode for code, tests and repositories. Most people never need it. Try it once Chat and Work feel routine.

Write and fix code

Describe a script or bug. Codex edits the files and runs the checks.

Work in a repository

Connect an approved code repository and ask for a change you can review before it lands.

Automations

Codex automations run on their own schedule, separate from ChatGPT Scheduled tasks.

Use Codex only with code and data your campus allows. Review every change before you use it.
